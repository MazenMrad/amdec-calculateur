Guide utilisateur (2 pages, à joindre au rendu)

1. Saisir (2 min)

  1. Renseignez d'abord le bloc d'entête (projet, responsable, système, équipe, date, révision).
  2. Cliquez Ajouter un mode (ou Modifier sur une ligne). Renseignez fonction, mode, effet, cause.
  3. Notez F, G, D de 1 à 5 avec l'onglet Échelles (ex. F=4 : environ 1 fois/mois).
  4. Pour chaque mode, ajoutez l'action corrective, son responsable et l'échéance, puis estimez F' et G' après action (D inchangée).
  5. Indiquez l'origine : observé (vu), rapporté (technicien/rapport), hypothèse (à signaler).

2. Lire les résultats

  1. C = F × G × D se calcule seul, ainsi que C' = F' × G' × D après action.
  2. Top 3 : actions prioritaires. Pareto : traitez les barres qui font 80 % du cumul.
  3. Matrice F×G : cases rouges : inacceptables, même avec un D faible.
  4. Comparaison avant/après : vérifiez que chaque C' passe sous le seuil (gain total affiché).

3. Exporter et démontrer en live

  1. Excel (2 onglets : AMDEC + Échelles), PDF (tableau + Pareto), CSV/JSON pour archivage.
  2. Données sauvegardées dans le navigateur (localStorage). Exportez le JSON avant de changer de PC.
  3. Démo soutenance : ajoutez un mode en direct, puis montrez C, le re-tri et le Pareto qui bouge.
